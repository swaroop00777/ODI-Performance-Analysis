# 🏏 ODI Cricket Team Performance Analysis  
### Power BI + Python Advanced Analytics Project

---

## 📌 Project Overview

This project analyzes ODI (One Day International) cricket team performance using **Power BI** for interactive dashboards and **Python** for advanced statistical and machine learning analysis.

The dashboard provides:

- Team performance comparison
- Win percentage analysis
- Venue-wise contribution
- Year-wise trend analysis
- Correlation between performance metrics
- Clustering & PCA analysis
- Network relationship visualization

This project demonstrates the integration of Business Intelligence and Data Science techniques in sports analytics.

---

## 🎯 Objectives

- Analyze ODI team performance metrics
- Identify patterns influencing match outcomes
- Compare team scoring distributions
- Perform correlation analysis
- Apply clustering and PCA for pattern detection
- Visualize advanced statistical insights using Python

## 📈 Key Analytical Techniques Used

### 🔹 Correlation Analysis
Identifies relationships between runs scored, overs played, wickets lost, and run rate.

### 🔹 K-Means Clustering
Groups matches based on performance similarity.

### 🔹 Principal Component Analysis (PCA)
Reduces multiple variables into principal components for pattern visualization.

### 🔹 Network Analysis
Visualizes interaction relationships between teams.

### 🔹 Distribution Analysis
Analyzes scoring consistency and density patterns.

## 📊 Key Insights

- Strong positive correlation between runs scored and run rate.
- Venue significantly impacts team performance.
- Teams show distinct scoring distribution patterns.
- Performance clusters indicate competitive balance.
- Network graph reveals highly interconnected teams.

## 🚀 How to Run

### Power BI
1. Open `ODI_Dashboard.pbix` in Power BI Desktop.
2. Refresh data if required.
3. Explore interactive dashboards.

### Python
Install required libraries:

```bash
pip install pandas matplotlib seaborn scikit-learn networkx
```

Run scripts:

```bash
python correlation_analysis.py
python clustering.py
python pca_analysis.py
```
